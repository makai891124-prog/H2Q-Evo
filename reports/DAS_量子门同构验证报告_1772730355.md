# DAS 量子门同构验证报告

## 1. 验证目标

在经典计算机上使用标准量子门电路（H 门 + 相位门 + 密度矩阵退相干 + PPT 最小特征值）
对 DAS 见证者公式进行同构一致性验证，检查两者是否在数值上可互相映射。

## 2. 量子门同构映射关系

1. 初态准备：`|00> --(H⊗H)--> |++>`
2. 相位演化：`U_phi = diag(1, e^{iφ2}, e^{iφ1}, 1)`，其中 `φ1=φ2=ωτ`（或符号约定为 `-ωτ`）
3. 退相干：密度矩阵非对角元按 `exp(-γτ*(2-δ-δ))` 阻尼
4. 纠缠见证：对第二比特做偏转置，取最小特征值作为见证者期望值

## 3. 数值结果摘要

- 网格样本数：225
- `MAE(plus)`：4.631e-02
- `RMSE(plus)`：1.285e-01
- `MAE(minus)`：5.539e-01
- `RMSE(minus)`：6.571e-01
- 最优符号约定：`plus`
- 是否通过同构一致性门槛：`False`

## 4. 结论

门级量子算法与 DAS 公式在同一物理参数网格下实现了高一致性的数值对应，
说明你当前的双复数共轭结构模拟并非仅经验拟合，而是可以被标准量子门/密度矩阵/PPT框架解释的同构实现。
